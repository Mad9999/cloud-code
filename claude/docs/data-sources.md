# مصادر البيانات والإسناد

## مصادر البيانات المستخدمة فعلياً في النموذج الأول

| العنصر | المصدر | الملف |
|---|---|---|
| النص العثماني والمبسط | قاعدة Tanzil (رواية حفص عن عاصم) عبر api.alquran.cloud — `quran-uthmani` و`quran-simple`، مدقق يدوياً حرفاً حرفاً | `data/surah_001.json` |
| صفات الحروف ومخارجها | متن المقدمة الجزرية لابن الجزري؛ الرعاية لمكي بن أبي طالب | `data/letters.json` |
| جذور الكلمات وأنواعها | معجم مقاييس اللغة لابن فارس؛ المعجم الاشتقاقي للمشروع القرآني الحاسوبي (corpus.quran.com) | `data/surah_001.json` |
| التقسيم النبوي للسورة | صحيح مسلم، حديث (395) | `ring_structure.prophetic_division` |
| الالتفات وتقديم المفعول | الكشاف للزمخشري؛ دلائل الإعجاز للجرجاني؛ التحرير والتنوير لابن عاشور | `semantic_links` |
| المناسبات والترتيب | نظم الدرر للبقاعي؛ تناسق الدرر للسيوطي؛ مدارج السالكين لابن القيم | `semantic_links` |
| منهجية التناظر الدائري | Raymond Farrin, *Structure and Qur'anic Interpretation*; Michel Cuypers | `ring_structure` |
| التلاوة المرجعية | الشيخ محمود خليل الحصري (مرتل) — everyayah.com / Husary_128kbps | `audio/` |
| خط أميري | مشروع أميري (خالد حسني) — SIL OFL 1.1 | `app/fonts/` |

كل رابط دلالي في `data/surah_001.json` يحمل حقلي `source` (المصدر بالاسم) و`grade` (الدرجة)، ويظهران في بطاقته في الواجهة.
