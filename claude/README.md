# مشروع الهندسة القرآنية — Qur'anic Engineering

> إن أصبتُ فمن الله وحده والحمد لله، وإن أخطأتُ فمن نفسي وأعوذ بالله.
>
> للتبليغ عن خطأ: رقم المطوّر <span dir="ltr">+966 50 766 4944</span>

منصة بحثية تفاعلية تدرس النص القرآني بأدوات العصر: التحليل الهيكلي (التناظر الدائري)، والشبكات الدلالية، والبصمة الصوتية التجويدية، والقياس الفيزيائي الترددي، واستنباط النماذج العملية — مع فصلٍ صارم بين القطعي والمأثور والاجتهادي.

**النموذج الأول (MVP): سورة الفاتحة** — سبع آيات، تسع وعشرون كلمة، خمس طبقات تحليل.

## التشغيل

الواجهة تعمل بلا خادم ولا إنترنت — افتح مباشرة:

```
claude/app/index.html
```

لإعادة توليد بيانات التحليل من المصدر الذهبي:

```bash
pip install -r claude/pipeline/requirements.txt
python3 claude/pipeline/build.py
```

## الطبقات الخمس

| الطبقة | المحتوى | درجة المعطى |
|---|---|---|
| ١ · الهيكل الدائري | التناظر المرآتي بين الآيات (١↔٧، ٢↔٦، ٣↔٥) حول المحور، والتقسيم النبوي للسورة، ونقطة الالتفات | اجتهادي + مأثور |
| ٢ · الشبكة الدلالية | خريطة قوى تفاعلية: كلمات وجذور ومحاور وآيات، مع ١١ رابطاً مُسنداً لمصادره | اجتهادي مُسند |
| ٣ · البصمة الصوتية | كل حرف ملوَّن على مقياس اللين↔الشدة المحسوب من صفاته التجويدية، ومخطط راداري يقارن الآيات | قطعي الصفات، اجتهادي المقياس |
| ٤ · التردد الفيزيائي | أطياف فورييه لتلاوة الشيخ الحصري آيةً آية، ومقارنة استكشافية بين التوقع النصي والقياس الفيزيائي | قياس فيزيائي |
| ٥ · النموذج العملي | الفاتحة كبنية «الطلب الراقي»: ثناء ← عهد ← طلب جامع ← تعريف بالقدوة والحدود | اجتهادي |

## بنية المشروع

```
claude/
├── data/           المصدر الذهبي المدقق يدوياً (نص السورة، الجذور، الروابط المسندة، صفات الحروف)
├── pipeline/       خط أنابيب بايثون: التفكيك الصوتي، بناء الشبكة، تحليل FFT، التحقق والبناء
├── audio/          تلاوة الفاتحة آية-آية (الحصري، everyayah.com)
├── app/            الواجهة التفاعلية (HTML/JS خالص، بدون أي اعتماد خارجي)
│   └── generated/  مخرجات build.py (مضمّنة في المستودع لتعمل الواجهة فوراً)
└── docs/           المنهجية ومصادر البيانات
```

## الضابط المنهجي

كل معلومة في المشروع موسومة بواحدة من ثلاث درجات، وتظهر في الواجهة كشارة ملوّنة:

- **قطعي**: النص القرآني (رواية حفص عن عاصم، قاعدة Tanzil) وصفات الحروف المتفق عليها في كتب التجويد.
- **مأثور**: منقول عن مصدر شرعي معتمد، مذكور بالاسم في بطاقته (صحيح مسلم، الكشاف، التحرير والتنوير، نظم الدرر، مدارج السالكين...).
- **اجتهادي**: استنباط من فريق المشروع قابل للخطأ والمراجعة (التناظر الدائري، مقياس الحدة، النموذج العملي، المقارنة النصية-الفيزيائية).

لا يُقدَّم أي نمط إحصائي على أنه «إعجاز مثبت» — بل ملاحظة قابلة للفحص والدحض.

## خارطة المراحل القادمة

1. تعميم خوارزميات التفكيك على سور أخرى (يتطلب تغطية التنوين والتاء المربوطة وأحكام النون الساكنة).
2. الروابط بين السور: بناء الشبكة العابرة للسور (الفاتحة ← البقرة نموذج أول موجود).
3. الهندسة العكسية للنزول: طبقة الترتيب الزمني والتدرج التشريعي.
4. محاذاة صوتية حرف-بحرف بين التلاوة والنص (forced alignment) لقياس تردد كل مخرج فعلياً.
5. النشر كموقع عام (المشروع جاهز للنشر الثابت كما هو).

- النص القرآني: قاعدة [Tanzil](https://tanzil.net) (رواية حفص).

- خط أميري: رخصة SIL OFL 1.1 — انظر `app/fonts/OFL.txt`.
- كود المشروع: نفس رخصة المستودع.
